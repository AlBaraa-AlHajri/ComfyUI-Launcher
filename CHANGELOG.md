# Changelog

## 1.0.0 — 2026-10-12

- Added Arabic/English splash, first-run discovery, settings and system-tray controls.
- Added venv and portable ComfyUI support, Chrome/Edge app mode and default-browser fallback.
- Added named-mutex activation, server identity checks and occupied-port recovery.
- Added cooperative shutdown, psutil fallback and Windows Job Object process containment.
- Added atomic user settings, UTF-8 rotating logs and startup diagnostics with copy/retry.
- Added original SVG workflow/play icon and reproducible multi-resolution Windows artwork.
- Added windowed PyInstaller packaging, shortcuts, tests and automated GitHub releases.
